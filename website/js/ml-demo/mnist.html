MNIST Digit Recognizer

Real CNN (Convolutional Neural Network) yang berjalan sepenuhnya di browser-mu. Tidak ada server, tidak ada API call — semua machine learning terjadi di perangkat-mu.

⏱️ Estimasi: training ~30 detik di laptop modern, ~1-2 menit di HP. Setelah training, gambar angka apapun di kanvas dan lihat prediksi model.

01

🏋️ Train Model

Model dilatih dari dataset MNIST (subset 5.000 gambar) langsung di browser.

Arsitektur Model

  • Conv2D 16 filter (3×3) → MaxPool 2×2
  • Conv2D 32 filter (3×3) → MaxPool 2×2
  • Flatten → Dense 128 → Dense 10
  • Total: ~108K parameter

ℹ️ Tentang Demo Ini

  • Training terjadi di browser — bukan di server. Data tidak meninggalkan perangkat-mu.
  • Subset 5.000 dari 60.000 gambar training dipakai untuk mempercepat demo.
  • Akurasi tipikal: 90-95% pada subset (full MNIST: 98%+ dengan epochs lebih banyak).
  • Limitasi: download TF.js ~1.2MB pertama kali, training ~30 detik.
