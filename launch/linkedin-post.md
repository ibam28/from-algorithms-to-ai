### Versi A — Storytelling (untuk jangkauan luas)

```
AI, Machine Learning, sama Algoritma — tiga istilah ini sering dipakai
bergantian. Padahal artinya beda.

Saya tanya 10 orang, 9 nggak bisa jelasin bedanya. Wajar — kebanyakan
penjelasan di internet cuma dua jenis: terlalu teknis (penuh rumus) atau
terlalu dangkal (sampai salah).

Jadi saya bikin satu proyek kecil untuk menjawab itu.

Pendekatannya sederhana: mulai dari yang paling akrab, jangan langsung
ke AI.

📐 Algoritma = resep masakan. Langkah pasti, hasil bisa diprediksi.
🤖 Machine Learning = koki yang belajar dari 10.000 percobaan. Nggak
   dikasih aturan, dikasih data.
✨ AI = restorannya. Koki, pelayan, kasir — semuanya.

Dan ini yang paling sering dilewatkan:
AI itu payung paling luas. ML cuma SALAH SATU cara untuk sampai ke sana.
Ada AI yang sama sekali bukan ML (symbolic AI), dan ada algoritma yang
sama sekali bukan AI (algoritma kuantum).

Algoritma itu ALAT.
Machine Learning itu CARA.
AI itu TUJUAN.

Yang bikin proyek ini beda: saya nggak berhenti di penjelasan.

Ada demo ML asli yang berjalan di browser kamu — tanpa server. Model CNN
dilatih di perangkatmu sendiri, kamu gambar angka, dia menebak. Kalau mau,
kamu bisa lihat proses training-nya berjalan real-time.

Semuanya open source. Link di komentar. 👇

Kalau bermanfaat, share ke satu orang yang masih bingung bedanya AI dan ML.

Dibuat oleh @ibam28 · Full Stack + AI Engineer

#AI #MachineLearning #Algoritma #Programming #BelajarAI
```

### Versi B — Problem-first (untuk audiens teknis / hiring manager)

```
Kebanyakan orang menyebut "AI" untuk semua hal — chatbot, rekomendasi
TikTok, algoritma sorting, semuanya disebut AI.

Akibatnya dua hal:
1. Ekspektasi soal AI jadi tidak realistis
2. Pekerjaan rekayasa yang sebenarnya beda, jadi terlihat sama

Saya bikin proyek kecil untuk memetakan hubungan ketiganya — dan saya
tunjukkan dengan kode, bukan cuma diagram.

Isinya:

📐 4 dokumen naratif — Algoritma, ML, AI, dan hubungan ketiganya.
   Ditulis untuk pembaca non-teknis, tapi tanpa menyederhanakan sampai salah.

🌐 Website interaktif — visualisasi sorting (bubble vs merge), decision
   tree trainer, diagram konsentris hubungan ketiganya, timeline AI 1950-2022.

🎯 Demo ML asli — CNN dilatih langsung di browser pakai TensorFlow.js.
   Dataset MNIST, 5.000 sampel. Tanpa server. Kamu gambar angka, dia
   menebak. Bisa lihat loss & accuracy update real-time.

🎞️ Slide deck 12 halaman — Reveal.js, single file.

🎬 Video script — 3 versi (100 detik untuk LinkedIn, 45 detik untuk Reels,
   3 menit untuk YouTube).

Catatan teknis:
· Vanilla JS + Canvas + SVG — tanpa framework, initial bundle < 100 KB
· TF.js dan D3 di-lazy-load pakai IntersectionObserver
· Canvas pakai Pointer Events — mouse, touch, stylus semuanya jalan
· WCAG 2.1 AA untuk konten naratif

Yang saya pelajari dari membangun ini: menjelaskan sesuatu dengan benar
itu lebih sulit daripada membangunnya.

Repo open source, link di komentar. 👇

#AI #MachineLearning #WebDevelopment #TensorFlow #Frontend
```

## 6. 24 Jam Pertama — Yang Harus Dilakukan

Ini yang menentukan jangkauan. LinkedIn menilai post dari engagement awal.

| Waktu | Aksi |
|---|---|
| 0 menit | Post + langsung tulis komentar berisi link, pin komentar |
| 0–15 menit | Balas setiap komentar yang masuk, secepat mungkin |
| 15–60 menit | Share link ke 2–3 grup/chat relevan (jangan spam) |
| 1–4 jam | Balas semua komentar baru. Ajukan pertanyaan balik agar thread panjang |
| 4–12 jam | Cek statistik: impresi, klik, profil visit |
| 12–24 jam | Balas sisa komentar. Jangan edit post (menurunkan jangkauan) |

**Jangan:**
- ❌ Edit post setelah publish (algoritma bisa menurunkan jangkauan)
- ❌ Hapus lalu repost (dianggap spam)
- ❌ Tag orang yang tidak relevan (spam)
- ❌ Balas komentar dengan satu kata ("thanks") — ajukan pertanyaan lanjutan

## 7. Re-share Setelah 1 Minggu

Pakai **Versi C** dengan hook berbeda. Bukan copy-paste post lama.

Formula re-share:
1. Hook baru (angle berbeda)
2. 1 insight yang belum disorot di post pertama
3. Link ke post pertama ("konteks lengkapnya di sini")
4. CTA sama

**Jangan** cuma bilang "posting ulang karena kemarin ramai" — itu tidak menambah nilai.

## 9. Kalau Ada Komentar Sulit

Antisipasi pertanyaan yang mungkin muncul:

| Komentar | Cara jawab |
|---|---|
| "Ini cuma teori, nggak ada implementasi" | "Ada demo live — training CNN jalan di browser. Coba aja." |
| "Kenapa nggak pakai React/Vue?" | "Target audiensnya non-teknis. Vanilla JS = bundle < 100 KB, load cepat di HP lama." |
| "Analogi dapur terlalu sederhana" | "Setuju, itu titik masuk. Dokumen lengkapnya di repo bahas nuansa — symbolic AI, counter-example." |
| "AI itu bukan cuma ML" | "Betul — itu justru poin utamanya. Diagram konsentris di website menunjukkan symbolic AI di luar ML." |
| "Bisa nggak dipakai untuk produksi?" | "Repo ini demo edukatif, bukan production. Tapi arsitekturnya (lazy-load, Pointer Events, a11y) bisa jadi referensi." |

**Prinsip:** jangan defensif. Kalau kritiknya valid, akui dan jelaskan batasannya.
