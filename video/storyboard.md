## Catatan Produksi Visual

### Sumber Aset

| Aset | Cara dapat |
|---|---|
| Slide deck | Rekam `slides.html` di browser (fullscreen, 1920×1080) |
| Demo MNIST | Rekam `website/js/ml-demo/mnist.html` (Chrome, 1920×1080) |
| Ikon app | Emoji native (jangan pakai logo trademark) |
| Diagram konsentris | CSS murni dari slides.html |
| Musik latar | YouTube Audio Library (gratis, no attribution) |

### Perekaman Layar

- **Resolusi:** 1920×1080 (16:9)
- **FPS:** 60 fps untuk animasi halus
- **Format:** MP4 (H.264) untuk upload, atau WebM untuk web
- **Tools gratis:** OBS Studio, Loom, QuickTime (macOS), atau GNOME Screencast (Linux)

### Editing

- **Cut:** Potong jeda panjang, sisakan napas 0,3–0,5s antar-scene
- **Zoom:** Zoom 5–10% pada bagian penting (pembeda aturan vs data)
- **Teks overlay:** Hanya untuk kata kunci, bukan subtitle penuh
- **Kontras:** Pastikan teks tetap terbaca di HP (min 28px pada 1080p)
- **Warna:** Pertahankan palet biru/oranye/ungu — jangan tambah warna baru

### Musik

- Ambient pelan, volume 15–20% di bawah voice-over
- Beat ringan boleh masuk di scene 8 (tiga kartu) untuk momentum
- Fade-out 1 detik di akhir

### Caption / Subtitle

- **Wajib** untuk LinkedIn (banyak orang nonton tanpa suara)
- Format: `.srt` atau auto-caption lalu edit manual
- Baris pendek, max 2 baris di layar, muncul 2–3 detik
