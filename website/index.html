01

📐 Algorithms

Definite steps to solve a problem. The recipe of computing.

🍳 Kitchen Analogy

An algorithm is like a recipe: "Heat oil for 2 minutes, sauté the garlic, add the rice, stir for 3 minutes." Every step is clear, it always finishes, and you can repeat it with consistent results.

5 Properties of a Good Algorithm

1

Input

Some starting data is provided

2

Output

Produces something

3

Definite

Unambiguous, clear steps

4

Finite

Always stops (no infinite loop)

5

Effective

Runs with reasonable resources

02

🤖 Machine Learning

Machines that learn from data, not from hand-written rules. The chef who learns from 10,000 tries.

🍳 Kitchen Analogy

If a regular algorithm is a chef who only cooks from recipes, ML is a chef who learns from thousands of attempts. Give them examples of dishes plus ratings, and they discover the "good recipe" pattern — and can invent new variations that are likely to taste great too.

Difference from Traditional Programming

Aspect Traditional Programming Machine Learning
Input Data + Rules Data + Correct answers
Output Answers Rules (a model)
Who finds the pattern? The programmer The ML algorithm
Updating rules Edit code manually Retrain with new data

✨ Artificial Intelligence

Machines that act "intelligently". The smart restaurant — chef, waiter, cashier, manager, all AI systems.

🍳 Kitchen Analogy

AI is not one thing — it is an umbrella name for many subsystems: 👨‍🍳 ML chef that adapts, 🗣️ NLP waiter that understands language, 👁️ CV cashier that recognizes faces, 📊 planning manager that optimizes. All working together.

📅 AI Timeline: 1950 → 2024

AI has existed since the 1950s. It is nothing new — what changed is the computing power and data that finally let old ideas run.
